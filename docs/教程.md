Windows 本地 Neo4j 导出，推荐用 **dump**。前提是知道你的数据库名，默认一般是 `neo4j`。

**1. 先停止 Neo4j**

如果是 Neo4j Desktop：在 Desktop 里点 Stop。  
如果是 Windows 服务：

```powershell
net stop neo4j
```

**2. 找到 `neo4j-admin`**

常见位置类似：

```text
C:\Program Files\Neo4j\neo4j-community-5.x.x\bin\neo4j-admin.bat
```

或者 Neo4j Desktop 项目目录里的：

```text
...\relate-data\dbmss\dbms-xxxx\bin\neo4j-admin.bat
```

**3. 导出 dump**

在 PowerShell 里执行，按你的实际路径替换：

```powershell
& "C:\path\to\neo4j\bin\neo4j-admin.bat" database dump neo4j --to-path="C:\Users\你的用户名\Desktop"
```

导出后桌面会有：

```text
neo4j.dump
```

**4. 如果不确定数据库名**

Neo4j 运行时查一下：

```cypher
SHOW DATABASES;
```

如果数据库叫 `medical`，导出命令就是：

```powershell
& "C:\path\to\neo4j\bin\neo4j-admin.bat" database dump medical --to-path="C:\Users\你的用户名\Desktop"
```
